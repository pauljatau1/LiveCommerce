# Maps address entry and buyer profile

Address forms in the shop and studio now offer street/building search and current location. Selected addresses carry area, LGA and coordinates through saving and Shipbubble quotes; changing a pin refreshes the verified-address cache and delivery price. The existing area picker stays available when Maps is unconfigured, fails to load or the user chooses manual entry. Outside-state addresses show the delivery notice and Notify me.

Pickup editing has its own studio screen and returns to the page that opened it. Buyer My profile adds details, phone, delivery-address management, password change and sign-out. Missing phone numbers are entered and saved inside bank-transfer consent, so buyers stay on the show.

Built on `fix/area-picker`. Per Paul's instruction, open this PR only after that branch is merged, then update this branch against `main`. Paul merges this PR. Existing manual address behaviour remains available as fallback; old pickup markup is retained behind its inactive flag.
