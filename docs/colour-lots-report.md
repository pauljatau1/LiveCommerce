## Design differences

- Reuse existing type and colour tokens. Swatches approximate indigo with `--accent`, rust with `--warm`, and cream with `--surface-sunken`; no new colours are introduced.
- If a colour has no photo, its row uses the product photo. Optional existing/new `colourQuantities[].image` values are preserved; this does not add a photo-upload flow.
- Running order is a compact view as in T5. Next opens the existing show-details form so scheduling, starting bids, duration and show notes still work. The original combined running-order section remains behind `LEGACY_COMBINED_RUNNING_ORDER=false`.
- Drag changes row order; a focusable handle also supports up/down arrow keys. The old move controls remain in the disabled combined section. Shows retain their existing maximum of 20 lots.
- Legacy auctions created without a colour are not retroactively assigned one. Their old stock path remains, rather than guessing from seller run notes.
